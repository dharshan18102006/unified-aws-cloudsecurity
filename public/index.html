AWS Access & Safe Provisioning Protocol

NEVER share AWS Root credentials or raw Secret Keys in chat or public repos.
Your cloud credentials should remain strictly on your local machine behind least-privilege IAM policies.

How to Safely Connect Your AWS Account:

  1. Simulation Mode (Default & Instant)
    No AWS account required. The system generates comprehensive CIS AWS benchmark audits automatically.
  2. Dedicated Read-Only IAM Role (Recommended for Live Audits)
    Create an IAM User with SecurityAudit managed policy only.
  3. Local AWS CLI Configuration
    aws configure
    AWS Access Key ID: YOUR_READONLY_KEY
    AWS Secret Access Key: YOUR_READONLY_SECRET
    Default region: ap-southeast-2
